# Bak flisene — et interaktivt 3D-bad

Et interaktivt 3D-baderom (prototype), laget for mobil: gå inn, ta på alt, se hva som skjuler seg bak flisene.

**Åpne rommet:** https://bitrazor.github.io/bak-flisene/

Prisene i rommet er en uforpliktende prisantydning basert på markedspriser (prisnivå oktober 2026), ikke et tilbud.

Lisenser: lyder, teksturer, modeller og skrifter står i `assets/LICENSES.md` (CC0 1.0 og SIL Open Font License 1.1); three.js er MIT (`vendor/three/LICENSE`).
