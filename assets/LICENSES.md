### How each licence was checked (2026-10-19)

- **ambientCG**: the licence page (https://docs.ambientcg.com/license/) says all assets are under the Creative Commons CC0 1.0 Universal licence and that credit is not needed.
- **Poly Haven**: https://polyhaven.com/license says the assets are CC0 and that credit is not needed. The downloaded files match the checksums (MD5) Poly Haven lists for them.
- **OpenGameArt packs**: the licence field of both pack pages reads CC0 (uploader: rubberduck; published 2018-06-29 and 2018-10-26). The first pack's page says it was recorded with an Android phone.
- **Kenney packs**: the `License.txt` inside each pack says Creative Commons Zero, CC0 ("Created/distributed by Kenney (www.kenney.nl)"; he asks for credit but says it is not mandatory), and kenney.nl lists both packs as CC0.
- **Font**: the SIL Open Font License 1.1 text that came with the font is shipped as `fonts/OFL.txt`. The font's copyright line reads "Copyright 2022 The Mona Sans Project Authors (https://github.com/github/mona-sans), with Reserved Font Name \"Mona\"". Removing glyphs counts as modifying the font (OFL FAQ 2.6), and a modified version may not keep the reserved name, so the subset is renamed inside the file to "Exhibit Sans"; the design is unchanged, the copyright line is kept, and the licence text travels with it.
- **Handwriting font**: Caveat's SIL Open Font License 1.1 text ships as `fonts/OFL-Caveat.txt`; its copyright line ("Copyright 2014 The Caveat Project Authors") names no Reserved Font Name, and the font ships exactly as downloaded (every build compares it byte for byte with the download).
- **Downloads intact**: every downloaded zip passed its integrity test and every unpacked file is byte-identical to its zip entry (run again by every build).
